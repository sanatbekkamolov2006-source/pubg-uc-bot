# PUBG Mobile UC Seller Bot

Ushbu Telegram bot PUBG Mobile o'yini uchun UC sotishga mo'ljallangan.

## Xususiyatlari
- Midasbuy narxlari asosida ishlaydi.
- Player ID orqali buyurtma qabul qiladi.
- To'lov cheklarini qabul qilish tizimi.

## O'rnatish
1. Kutubxonalarni o'rnating:
   ```bash
   pip install -r requirements.txt
   ```
2. `.env` fayliga bot tokeningizni yozing.
3. Botni ishga tushiring:
   ```bash
   python main.py
   ```
